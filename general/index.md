# General

The Toluna Start API is a REST API that supports secure integration with the Toluna platform. It covers survey management, raw data extraction, and supporting metadata.

## Core Capabilities

| Capability | What it supports |
| --- | --- |
| Survey management | Create, clone, update, delete, launch, pause, and monitor Toluna Start surveys. |
| Data extraction | Download raw respondent data for Toluna Start A/DIY surveys and eligible Full Service surveys. |
| Metadata | Retrieve supporting lookup values such as cultures, workspaces, categories, and research categories. |

The public Swagger UI remains the detailed source for endpoint request and response models:
