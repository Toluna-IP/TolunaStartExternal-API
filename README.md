# Toluna Start API Guide

This repository contains a Just the Docs-based online copy of the Toluna Start API documentation.

The guide content is based on the original PDF and is organized into:

- Overview
- Metadata API
- Survey Management API
- Data Extraction API
- How-To Guides

## Local Preview

Install dependencies and run Jekyll:

```bash
bundle install
bundle exec jekyll serve
```

The generated site is written to `_site`.
